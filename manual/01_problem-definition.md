## 01. 문제 정의

#### 1.1 프로젝트 배경

본 프로젝트는 제한된 물리 서버 자원 환경에서 5개의 독립 팀이 각각 다른 서비스를 운영해야 하는 상황에서 시작되었다.

물리 인프라는 한정되어 있었으며, 각 팀은 서로 간섭 없이 독립적인 개발 및 운영 환경을 요구하였다.

이에 따라 단순한 VM 분리가 아닌, **인프라 수준에서의 논리적 격리 아키텍처 설계**가 필요하였다.

---

#### 1.2 주요 문제

##### ① 자원 충돌 문제
- CPU 및 Memory 자원 경합 발생 가능
- 스토리지 I/O 병목 현상
- 특정 팀의 과도한 자원 점유로 인한 전체 성능 저하 위험

##### ② 네트워크 간섭 문제
- 동일 네트워크 사용 시 브로드캐스트 트래픽 증가
- IP 및 포트 충돌 가능성
- 팀 간 서비스 접근 가능성 존재

##### ③ 보안 위험
- 서비스의 직접적인 공인 IP 노출 가능성
- 관리 네트워크 외부 노출 위험
- 팀 간 Lateral Movement 가능성 (침투 확산 위험)

---

#### 1.3 해결 목표

본 프로젝트는 다음과 같은 목표를 기반으로 설계되었다.

- 논리적 및 물리적 격리를 통한 멀티테넌트 환경 구축
- 네트워크 세그멘테이션 기반 트래픽 분리
- 최소 권한 원칙 기반 접근 제어
- 안전한 원격 접속 환경 (VPN) 구축
- 제한된 물리 자원 내 효율적인 리소스 분배

---

#### Summary

본 프로젝트는 하이퍼바이저 기반 가상화 환경을 활용하여,
제한된 온프레미스 자원 환경에서도 다수의 독립 팀이 안전하게 공존할 수 있는
멀티테넌트 인프라 아키텍처를 설계하는 것을 목표로 한다.
